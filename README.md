# PickMe Mobile App – Manual Testing Project

This repository contains the manual testing work completed for the **PickMe Mobile App**, focusing on core mobile workflows such as splash screen, permissions, login, and ride booking. The project demonstrates structured QA documentation, real-world mobile testing practices, and detailed test case design.

---

## 📌 Project Scope
- Splash Screen  
- Permissions (Location, Notifications)  
- Login / OTP  
- Ride Booking Workflow  
- GPS & Location-based features  
- UI/UX flows
